# Spoonful

Live deployment: _in progress_

## What's done

- Backend supports full CRUD for recipes, connected to the frontend
- Signup, login, and logout are implemented and unit tested
- Routing set up for all main pages
- Responsive layout using Flexbox
- Matches the Figma design system: colors, fonts, buttons, and layout
- Unit tests for core components and utility functions
- End-to-end tests covering the main user flows
- Uses Context API and useReducer for auth state
- CI/CD pipeline with GitHub Actions, runs tests automatically on every push
